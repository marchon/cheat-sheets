Markdown Cheat Sheet

A cheatsheet of Markdown and Markdown Extra. See the the complete Markdown syntax for extra tasty details, and remember that Markdown Extra isn’t Markdown (but it’s sometimes handy).

## Markdown plus tables ##

|  Cell  |  Cell  |   $10  |

* Outer pipes on tables are optional
* Colon used for alignment (right versus left)
