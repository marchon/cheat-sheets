dive
A tool for exploring a Docker image, layer contents, and discovering ways to shrink it.
More information:
https://github.com/wagoodman/dive
.
Analyze a Docker image:
dive {{your_image_tag}}
Build an image and start analyzing it:
dive build -t {{some_tag}}
