paci
A package manager for Bash scripts.
More information:
https://github.com/tradebyte/paci
.
Update the list of available packages and versions (it's recommended to run this before other
paci
commands):
paci refresh
Configure its behaviour:
paci configure
Search for a given package:
paci search {{package}}
Install a package:
paci install {{package}}
Update a package:
paci update {{package}}
