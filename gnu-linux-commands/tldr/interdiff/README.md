Show differences between two diff files.
More information:
http://freshmeat.sourceforge.net/projects/patchutils
.
Compare diff files:
interdiff {{old_file}} {{new_file}}
Compare diff files, ignoring whitespace:
interdiff -w {{old_file}} {{new_file}}
