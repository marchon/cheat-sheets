grumphp
A PHP Composer plugin that enables source code quality checks.
More information:
https://github.com/phpro/grumphp
.
Register the Git hooks:
grumphp git:init
Trigger the pre-commit hook manually:
grumphp git:pre-commit
Check every versioned file:
grumphp run
