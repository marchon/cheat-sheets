An MQTT broker.
More information:
https://mosquitto.org/
.
Start mosquitto:
mosquitto
Specify a configuration file to use:
mosquitto --config-file {{path/to/file.conf}}
Listen on a specific port:
mosquitto --port {{8883}}
Daemonize by forking into the background:
mosquitto --daemon
