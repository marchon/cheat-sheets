git rm
Remove files from repository index and local filesystem.
More information:
https://git-scm.com/docs/git-rm
.
Remove file from repository index and filesystem:
git rm {{file}}
Remove directory:
git rm -r {{directory}}
Remove file from repository index but keep it untouched locally:
git rm --cached {{file}}
