sdkmanager
Tool to install packages for the Android SDK.
More information:
https://developer.android.com/studio/command-line/sdkmanager
.
List available packages:
sdkmanager --list
Install a package:
sdkmanager {{package}}
Update every installed package:
sdkmanager --update
Uninstall a package:
sdkmanager --uninstall {{package}}
