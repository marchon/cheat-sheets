eslint
A pluggable linting utility for JavaScript and JSX.
More information:
https://eslint.org
.
Create ESLint config:
eslint --init
Lint on a given set of files:
eslint {{filename}}.js {{filename1}}.js
Fix lint issues:
eslint --fix
Lint with config:
eslint -c {{path/to/config_file}} {{app/src}}
